# Multimodal-Interaction-Response-in-Older-Adults-MIROA-Dataset
Multimodal Interaction Response in Older Adults (MIROA) Dataset

[Dataset Overview]
The Multimodal Interaction Response in Older Adults (MIROA) Dataset contains cognitive and affective user experience responses collected from 124 older adults in a smart fitness mirror context. The dataset was developed to investigate how older users respond to different forms of system feedback and to support research on multimodal interaction, user experience, user modeling, adaptive interaction, and data-driven interaction design.

Participants experienced a video-based smart fitness mirror scenario involving a chair-squat exercise. A between-subject experimental design was used, in which each participant experienced one of four feedback conditions: No Feedback, Visual Feedback, Auditory Feedback, or Multimodal Feedback. Participants did not experience all four conditions. After viewing the scenario corresponding to their assigned condition, participants evaluated their anticipated interaction experience using a multidimensional questionnaire measuring cognitive and affective responses.

The dataset includes participant characteristics, assigned feedback condition, and 25 item-level user response variables measured on five-point Likert scales. The response measures comprise five cognitive dimensions and three affective dimensions. This item-level structure enables the dataset to support not only comparisons between experimental conditions but also response-driven analyses of individual differences among older users.

[Participants]
The dataset contains responses from 124 older adults aged 75–85 years. The mean participant age was 81.5 years (SD = 3.0). The sample included 58 men and 66 women. Additional background information, including weekly exercise frequency and smart-device usage frequency, was also collected.

[Experimental Context and Design]
The study used a video-based smart fitness mirror exercise scenario involving a chair-squat exercise. Prototype videos were used to provide participants with controlled representations of interaction with a smart fitness mirror and to ensure consistent presentation of the experimental stimuli.

A between-subject design was employed. Each participant was assigned to and experienced only one of the four feedback conditions. Therefore, the dataset should not be interpreted as repeated measurements of the same participants across four feedback conditions.

The four experimental conditions were:
1) No Feedback: The exercise scenario was presented without additional visual or auditory exercise feedback.
2) Visual Feedback: Exercise-related feedback was communicated visually, including text/captions and color-based visual guidance.
3) Auditory Feedback: Exercise-related feedback was communicated through auditory information, including spoken guidance and sound effects.
4) Multimodal Feedback: Visual and auditory feedback were combined to communicate exercise-related information through complementary sensory channels.

[User Experience Measures]
User experience was assessed using 25 items on a five-point Likert scale, comprising 15 cognitive response items and 10 affective response items.

1) Cognitive Response
-Clarity (Davis, 1989)
cr1: I felt that interacting with this system would be clear and easy to understand.
cr2: I felt comfortable with the way I would interact with this system.
cr3: I felt that I would be able to use this system easily in the way I wanted.

-Memorability (Schwarzer & Jerusalem, 1995)
cr4: I felt that using this system would help me solve difficult problems whenever they arise.
cr5: I felt that using this system would make it easier to stay focused on my goals and achieve them.
cr6: I felt that using this system would help me handle unexpected situations effectively.

-Cognitive Effort (Paas & van Merriënboer, 1994)
cr7: I felt that understanding the information provided by this system would require little mental effort.
cr8: I felt that understanding the content provided by this system would not require much effort.
cr9: I felt that using this system would not impose a high cognitive load.

-Error Management (Reason, 1990)
cr10: I felt that using this system would allow me to immediately recognize when I made a mistake.
cr11: I felt that using this system would allow me to correct errors easily.
cr12: I felt that this system would provide accurate feedback when an error occurred.

-Ease of Use (Davis, 1989)
cr13: I felt that learning how to operate this system would be easy.
cr14: I felt that I would be able to become proficient in using this system.
cr15: Overall, I felt that this system would be easy to use.

2) Affective Response
-Sense of Security (Lee & Moray, 1992)
er1: I felt that I would be able to trust this system.
er2: I felt that I would be confident when using this system.
er3: I felt that I would be safe when relying on this system.

-Immersion (Jackson & Marsh, 1996)
er4: I felt that using this system would allow me to fully concentrate on the task I was performing.
er5: I felt that using this system would allow me to become fully absorbed in learning the exercise.
er6: I felt that using this system would allow me to become fully immersed in what I was doing.

-Acceptance (Davis, 1989)
er7: I felt that using this system would be useful for learning the exercise.
er8: I felt that using this system would allow me to learn the exercise more quickly.
er9: I felt that using this system would increase my productivity.
er10: I felt that using this system would make learning the exercise easier.
